# Exclusive-101 — Full-Stack E-Commerce Platform

Exclusive-101 is a full-stack e-commerce web application built with Django and styled using Tailwind CSS. It features user authentication, account management, product browsing, and an interactive frontend UI.

## Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML, Tailwind CSS, JavaScript
* **Database:** SQLite (Development) / PostgreSQL (Production)
* **Deployment:** DigitalOcean, Nginx, Gunicorn

## Key Features

* User registration, login, and profile management
* Responsive product catalog and category filters
* Custom dynamic templates and modular UI components
